# Changelog

## 1.5

### General

- Added one-time pre-race briefings for each race weekend, created as soon as the next race is assigned.
- Improved world news so season openers can reference last season's close battles and no longer show 0-point preseason title fights.
- Added team personalities, team expectations, and stronger team welcome messages.
- Added inbox messages from drivers when they become full red rivals.
- Added Co-op driver perspective switching, per-player rivalry views, per-player rival messages, and a foundation for future Rivals Mode.
- Improved Co-op presentation with clearer dashboard view switching, active-driver inbox labels, per-driver pre-race rivalry notes, and per-driver season recap results.
- Restyled the Messages screen with news-style cards, category badges, color stripes, red rival messages, Delete Read, and per-message delete controls.
- Improved post-result flow so the sim progress screen appears before world calendar simming starts.
- Removed the standalone Drivers To Watch email because pre-race briefings now cover that information.
- Added a Settings credits section with proper credit to EverlastingApex and Apex Rivals for project inspiration and AMS2 car image resources.
- Clarified championship grid sizing so `Max_Opp` is treated as total grid size, including player and co-op drivers.

### AMS2

- Updated AMS2 cars and tracks to the latest available data.
- Added race setup roster validation before entering a race.
- Added Race Control messages for roster refresh and roster validation failures.

### iRacing

- Updated iRacing cars and tracks to the latest available data.
- Fixed difficulty sync so post-race and manual difficulty changes can recover the active season JSON path when older saves are missing it.
- Merged iRacing team paint colors into the team welcome email.

## 1.4

- Adjusted settings menu.
- Added folder location verification warnings for iRacing and AMS2 settings.
- Added select-all options for AMS2 owned car and track DLC lists.
- Added a hover volume slider for main menu music.
